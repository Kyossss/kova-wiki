# Kova Plugins

Plugins for Paper servers.

| Plugin | What it is | Price |
|---|---|---|
| [KovaLib](kovalib/index.md) | Menus that work under shaderpacks. A library that other plugins draw their menus with. | Free |
| KovaProfile | Several profiles per player, picked on a menu when they join. *Coming soon.* | Paid |

New here? If you're running a server, start with [Installing KovaLib](kovalib/installation.md).
If you're writing a plugin, start with [Getting started for developers](kovalib/developers/getting-started.md).
